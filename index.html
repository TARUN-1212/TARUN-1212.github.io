I'm Sai Tarun Baratam, a researcher focused on building hardware that is secure against both classical and quantum threats.

My work lives at the crossroads of post-quantum cryptography and hardware implementation — designing and attacking cryptographic circuits on FPGAs and ASICs, with a particular interest in side-channel attacks like power and electromagnetic analysis.

I work on efficient hardware architectures for NIST PQC standards (Kyber, Dilithium, SPHINCS+) while simultaneously investigating their physical vulnerabilities — because a mathematically secure algorithm can still leak secrets through its silicon.

Projects

⚡
PQC Hardware Suite
Hardware implementations of NIST PQC finalists (Kyber, Dilithium, SPHINCS+) on Xilinx FPGAs. Benchmarked for throughput, area, and power. Includes masked implementations against DPA.
VHDL Xilinx Vivado CRYSTALS-Kyber NTT
🔬
SCA Testbench
Automated side-channel acquisition and analysis framework using ChipWhisperer. Implements CPA, DPA, and t-test leakage detection for evaluating cryptographic hardware security.
Python ChipWhisperer CPA / DPA Power Traces
🛡️
Masking Compiler
Tool to automatically insert Boolean masking countermeasures into HDL designs. Transforms unprotected RTL into first-order DPA-resistant implementations with minimal overhead.
SystemVerilog Python Masking RTL Transform
🏗️
ASIC NTT Core
High-speed Number Theoretic Transform core designed for ASIC in 45nm. Pipelined butterfly architecture achieving sub-ns critical path. Synthesized and verified with Cadence Genus.
Verilog Cadence 45nm NTT
📡
EM Leakage Mapper
Spatial EM analysis tool using near-field probing to map leakage hotspots on ICs. Integrates with oscilloscope control software for automated XY-stage scanning and trace collection.
Python EM Analysis NumPy Hardware
🔐
PQC Protocol Stack
Software/hardware co-design for a post-quantum TLS handshake using Kyber KEM + Dilithium signatures. Runs on FPGA-accelerated embedded platform with real-time key exchange.
C VHDL TLS Kyber KEM
